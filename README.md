# FRAMEHAUS — Premium Photography & Cinematic Studio

A high-end, responsive web application and portfolio experience for **FRAMEHAUS**, an editorial, commercial, and cinematic photography studio.

---

## ✨ Features

- **Cinematic Hero**: Ambient video canvas with smooth playback, custom controls, and typography.
- **Curated Showcases**: Editorial disciplines featuring high-resolution fashion, architecture, and fine art portraits.
- **Interactive Studio Gallery**:
  - Filterable by **Photos** and **Videos**.
  - Adaptive aspect ratio grids for portraits, reels, and landscape footage.
  - High-performance lightbox modal with full image previews and video playback controls.
- **Responsive & Accessible**: Seamless fluid scaling from mobile handsets to ultra-wide desktop monitors.
- **Self-Contained Local Assets**: High-speed loading without external drive links or dependencies.

---

## 🛠️ Tech Stack

- **HTML5 & Vanilla CSS3**: Semantic layouts, glassmorphism, responsive CSS Grid / Flexbox.
- **JavaScript (ES6+)**: Custom lightbox, filter state management, video canvas controllers.
- **Typography**: Cormorant Garamond, Inter, Outfit, and Plus Jakarta Sans.

---

## 🚀 Getting Started

To run the project locally:

```bash
# Clone the repository
git clone https://github.com/SYED1238/photostudio.git

# Navigate into the project directory
cd photostudio

# Run locally using any static web server (e.g. npx serve)
npx serve -l 3001 .
```

Open [http://localhost:3001](http://localhost:3001) in your browser.
